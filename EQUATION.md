# The equation RTE2D solves

The exact formulation of the learned problem, as implemented in `src/deeponet.py`
(`pde_residual`) and generated by `src/prepare_data.py`. Boundary conditions are
deliberately left aside here.

## 1. The PDE

The 2D radiative transfer equation (RTE), **steady**, **grey**, in an
**absorbing–emitting, non-scattering** medium:

```
  μ · ∇ₓ I(x, μ)  =  κ(x) · [ I_b(x) − I(x, μ) ] ,        I_b = (σ/π) · T(x)⁴
```

that is, in coordinates, exactly the form of the code
(`residual = transport − (u1_eval + u2_eval · I)`):

```
  sin φ ∂I/∂x  +  cos φ ∂I/∂y  =  u₁(x)  +  u₂(x) · I

  with   u₁ = κ · (σ/π) · T⁴     (emission, the source)
         u₂ = −κ                 (extinction by absorption)
```

Nature: a **linear, first-order, hyperbolic** PDE. The left-hand side is a directional
derivative along the ray of direction μ. Since there is **no scattering term**
(`radiant_fraction = 0` in the H5; `aLambda_0` is the only coefficient), there is no
phase integral ∫ Φ(μ→μ′) I dμ′: **the directions are decoupled** and communicate only
through the shared κ and T fields. Each direction is therefore a scalar ODE along its
characteristic, with formal solution

```
  I(s) = I(0)·e^{−∫₀ˢ κ}  +  ∫₀ˢ κ(s′) I_b(s′) e^{−∫_{s′}^{s} κ} ds′
```

## 2. The variables, and where they live

| Object | Space | Units / observed range |
|---|---|---|
| `x = (x, y)` — position | Ω = (−1.5, 1.5) × (0, 3) ⊂ ℝ², a 150×150 mesh = 22 500 cell centres (centres from −1.49 to 1.49 and from 0.01 to 2.99) | m |
| `φ` — propagation direction | S¹: μ = (sin φ, cos φ), φ ∈ [0, 2π). **One single angular degree of freedom.** Data on 16 FVDOM ordinates φ_m = 2πm/16 | dimensionless |
| **`I(x, φ)` — the unknown**, radiative intensity | Ω × S¹ → ℝ₊ | W·m⁻²·rad⁻¹ |
| `κ(x)` — absorption coefficient (`aLambda_0`) | Ω → ℝ₊ | m⁻¹, ∈ [0.10, 4.24] |
| `T(x)` — temperature | Ω → ℝ₊ | K, ∈ [300, 1455] |
| `σ` — Stefan–Boltzmann constant | constant | 5.670374419e-8 W·m⁻²·K⁻⁴ |

The derived quantity used in the metrics and figures is the **incident radiation**:

```
  G(x) = ∫₀^{2π} I(x, φ) dφ      ≈  (2π/16) · Σₘ I(x, φₘ)      (uniform quadrature)
```

The repository has a single angular convention: **φ is measured from +y clockwise**,
φ = atan2(μx, μy), matching the FVDOM ordinates of the solver. **Every** direction
vector is built through `utils.dirs_from_phi` / `utils.transport_coeffs`, and query
points are always stored as three columns `(x, y, φ)` — that is what the dataset holds
and what the trunk (or the Transformer-Based DeepONet coordinate decoder) receives.

## 3. What `t` is not

The 6001 snapshots (starting at t = 10 s, Δt = 10⁻² s) are **not** a time evolution to
be solved. Radiation is assumed instantaneous compared with the fire dynamics: each
snapshot is an **independent steady problem** with its own (T, κ) fields. Time only
indexes the samples — and the `.pt` index is not even chronological (the `time_*` groups
are sorted alphabetically).

What is learned is therefore not a trajectory but the **parameter-to-solution operator**:

```
  G† :  (T, κ) ∈ C(Ω)²  ⟶  I ∈ C(Ω × S¹)
```

Hence the DeepONet structure: the branches encode (T, κ) — through PCA, an autoencoder
or the Transformer-Based DeepONet — into a latent c; the trunk takes the query point
y = (x, y, φ) and produces a basis t; then

```
  I = softplus( c · t + b ) · I_scale
```

the `softplus` enforcing I ≥ 0, a physical constraint of the PDE (a radiative intensity is
non-negative). The Transformer-Based DeepONet keeps the same output nonlinearity but
replaces the separable `c · t` by cross-attention of the coordinate embedding on the
latent tokens.

## 4. Residual and physics loss

The pointwise residual evaluated by `pde_residual` (derivatives by exact autodiff, with
the trunk Jacobian shared across snapshots) is

```
  r(x, φ) = ( sin φ ∂ₓI + cos φ ∂_yI ) − ( u₁ + u₂ I )
```

It serves either as a **loss** (hybrid runs, `--w_phys`) or as a plain **quality
metric** — the data coming from an FVDOM solver, a purely data-driven model has to
respect the RTE as well. The normalisations used are ρ = RMS(r)/RMS(S) and RMS(r)/max(I).
